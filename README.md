# tanmoy-git.github.io/resume

Personal site for Tanmoy Bhattacharjee, Senior Engineering Manager.

A single static page (`index.html`) with inline CSS, inline SVG icons and a few lines of vanilla JS: no framework, no build step, no external requests. Pushing to `main` deploys it to GitHub Pages via `.github/workflows/deploy.yml`.

- `index.html` – the site
- `assets/` – résumé PDF, favicon, social preview image
